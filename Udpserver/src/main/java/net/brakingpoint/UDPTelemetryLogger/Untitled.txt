I see the source of the confusion. In Forza Horizon 5, if you only have a single "Data Out" toggle (and no "Sled/Dash" selector), the game is using the legacy FH4/FH5 packet structure.
While very similar to Motorsport, there are a few critical differences in the offsets. Specifically, Position X does not start at 232 in the standard Horizon 1-toggle format.
Here is the exact map for the FH5 "Data Out" packet that you are looking at:
1. The Physics Block (Bytes 0–231)
This part is identical to the "Sled" format you already have. It ends with NumCylinders at byte 228.
2. The Horizon Extension (The "Dash" data)
In the Horizon-only format, the game inserts Throttle, Brake, and Steering as Floats (4-bytes each) right after the physics block, which pushes everything else down.
| Offset | Type | Property |
|---|---|---|
| 232 | f32 | Throttle (0.0 to 1.0) |
| 236 | f32 | Steering (-1.0 to 1.0) |
| 240 | f32 | Brake (0.0 to 1.0) |
| 244 | f32 | Clutch (0.0 to 1.0) |
| 248 | f32 | Handbrake (0.0 to 1.0) |
| 252 | f32 | Gear (1.0, 2.0, etc.) |
| 256 | f32 | Position X |
| 260 | f32 | Position Y |
| 264 | f32 | Position Z |
Why this is different from your current code:
If you use your current forzaDash.java (which expects Motorsport's 336-byte layout) on this Horizon stream:
 * Your PositionX will be wrong: Your code looks at byte 232 and expects a float. In FH5, byte 232 is indeed a float, but it's Throttle, not Position.
 * Your Accel will be wrong: Your code looks at byte 303 for a 1-byte integer. In this FH5 format, that byte will be part of a completely different floating-point value (likely Tire Temperature or Fuel).
How to fix it for Horizon 5
If you want to support this specific FH5 format, you need to shift your offsets in the constructor.
The "Float of Throttle" you were looking for is exactly at Byte 232.
If you want to see if your packet is 324 bytes (FH5 standard) vs 336 bytes (Motorsport), you can add a check at the start of your constructor:
// Logic to detect if we are in Horizon vs Motorsport
if (data.length < 336) {
    // We are in Horizon 5 (Single Toggle mode)
    this.ThrottleFloat = readFloat(data, 232); 
    this.PositionX = readFloat(data, 256);
} else {
    // We are in Motorsport (336-byte Dash mode)
    this.PositionX = readFloat(data, 232);
    this.AccelByte = data[303] & 0xFF;
}

Summary: You were right—in that specific FH5 "Data Out" mode, byte 232 is a float of Throttle, and Position doesn't start until byte 256. Motorsport changed this by moving the inputs (Throttle/Brake) to the end of the packet as 1-byte integers to make room for more suspension and tire data.
